# Source provenance

The P2P overview was imported unchanged from the owner's `Raast_P2P_Module_1_Training_Package.zip`. The P2P Remittance overview in `modules/02-p2p-remittance/` adapts that Module 1 document and aligns it with the supplied home-remittance specifications. Discovery and payment messages stay the same. A remittance is transaction type 005 and carries the extra origin and conversion details used for the beneficiary credit and e-PRC. The overview does not reproduce API fields or message schemas. The remaining modules are planning placeholders. This publication does not independently certify current Raast protocol specifications.

Assessment files are maintained in a private repository and are not part of this public repository's source or history.
