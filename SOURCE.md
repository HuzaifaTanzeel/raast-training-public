# Source provenance

The P2P overview was imported unchanged from the owner's `Raast_P2P_Module_1_Training_Package.zip`. The P2P Remittance overview in `modules/02-p2p-remittance/` adapts that Module 1 document. It keeps the same discovery methods and payment messages, and changes the roles and wording to a remitter and a beneficiary. It was not imported from a separate validated package. The remaining modules are planning placeholders. This publication does not independently certify current Raast protocol specifications.

Assessment files are maintained in a private repository and are not part of this public repository's source or history.
