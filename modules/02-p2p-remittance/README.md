# P2P Remittance

Read the [P2P Remittance Overview](02_Raast_P2P_Remittance_Overview.md), including embedded Mermaid sequence diagrams.

The overview follows the same structure as the [P2P Payment Overview](../01-p2p/01_Raast_P2P_Payment_Overview.md). A remitter sends funds to a beneficiary. Title verification can use a Raast ID (alias), an IBAN, or a legacy account number. The payment messages and exception handling match Module 1; only the remittance wording changes.

No separate interactive assessment is published for this module yet. Ask your instructor if an assessment is assigned. Quiz source files and answer keys are not part of this public repository.
